# Jume UI/UX v1 规范

本页是 Jume 桌面 v1 界面与交互的实现依据。视觉稿在作者的 claude.ai Design 画布“Jume 桌面 UI/UX”
（私有），导出的参考图在 `docs/design/jume-ui-v1/`。产品范围与负责代码见
[Jume 桌面需求](DEVICE-SHELL.md)（U1）。落地后，数值的代码权威是 `controls/Theme.qml` 与
[共享控件](../mainline/gaming-shell/controls/README.md)；本页保留设计意图、按键规则与验收标准。
安全、证据与清理规则以 [AGENTS](../AGENTS.md) 为准。

## 1. 屏幕与单位

- R46H 面板 1024×768、4 英寸、约 320 ppi（12.6 px/mm）。逻辑 1 单位 = 1 物理像素。
- 正文 24 px ≈ 1.9 mm；可读下限 18 px ≈ 1.4 mm；只有按键徽标内的字母可用 16–19 px。
- “界面字号” 90 / 100 / 115 / 130%：只缩放文字，行高随内容增长；不缩放整页。
- 其他比例：高度固定 768 单位，宽度 = 768 × 宽高比（3:2 → 1152，16:9 → 1365，1:1 → 768）。
  左右边距 = max(40, 宽 × 4%)；宽度 ≥ 900 时设置为双栏，否则分类与详情变为前后两级。
  网格列数 = ⌊(内容宽 + 32) ÷ (212 + 32)⌋，余量平均分给列宽，最多放大 12%。

## 4. 版面、圆角、层级、焦点、列表

- 间距 4 / 8 / 12 / 16 / 24 / 32 / 40 / 48；组内 4，行间 8。
- 版面：顶栏 72（左右边距 40，右侧 Wi-Fi、电量、时间）；提示栏 64（顶部 1 px outline）；内容区 944 × 632。
- 圆角：8 肩键徽标 · 12 键盘按键 · 16 行与按钮 · 20 网格卡 · 24 大卡片 · 28 面板、浮层、入口图块。
- 层级：0 ground；1 surface（必要时 1 px outline）；2 抬起（聚焦卡片、面板，用预渲染
  BorderImage 阴影）；3 遮罩（纯色透明度）。禁止实时模糊和多层阴影。
- 焦点框：4 px focus 色描边，与元素之间留 3–4 px 间隙，间隙颜色 = 元素所在容器的底色；
  圆角 = 元素圆角 + 7。卡片聚焦放大到 1.04 并抬起，行不放大。同屏只有一个焦点框：浮层（Sheet、Dialog、快捷面板）打开时，
  底层页面的焦点框隐藏，卡片保持抬起；
  “选中但未聚焦”（如当前设置分类）用 accentSoft 底 + accentInk 粗体；正在调整的滑块焦点框为 warning。
- 列表：每行是独立的圆角面（surface，r16），行间 8 px，不画分割线。分割线只用于划分区域
  （顶栏/提示栏、浮层头尾、快捷面板滑块与操作之间）。行高 72（单行）/ 96（带说明或滑块）；
  焦点目标高 ≥ 56；行内只放一个可调控件；分区标题 caption，左缩进 24 与行文字对齐。
- 图标：24 网格、2 px 线、圆头圆角；显示尺寸 24 / 28 / 40 / 64；始终配文字标签。

## 5. 组件

- **Button**：高 56、r16、文字 24/500、左右内边距 28。主要（accent 底白字）、次要（surfaceSunken）、
  危险（平时 surfaceSunken 底 danger 字，聚焦后实心 danger 底白字）。按下缩放 0.97 并加深；
  禁用为浅底 + #8E99A1 字。一屏最多一个主要按钮。
- **ListRow**：基本（chevron）、选择（数值 + chevron，打开 ChoicePopup）、开关、说明（第二行
  caption）、滑块（96 高，←→ 直接调整）、只读（右侧数值）、禁用（仍可停留焦点，第二行写原因）。
- **Switch** 轨道 64×36、拇指 28；开 = accent，关 = #C9D0D5。**Slider** 轨道 8、拇指 28
  （外圈 3 px accent），调整中拇指 36、warning 色，每步 5%。**ProgressBar** 高 8；不确定进度在
  减少动态效果时静止显示一段。
- **Tabs**（分区标签）：48 高胶囊，文字 22；当前 = text 底白字；两端放 L1 / R1 浅色徽标；
  L1/R1 切换时焦点不移到标签上。
- **GameCard**：主页 256×256 r24；网格 212×212 r20，标题 22 在图下方。有封面只显示图；
  无封面回退 = 系统色 + 135° 斜纹（白 7%，14 px）+ 白色标题（主页卡片上显示，网格省略）。
  状态徽章（“已暂停”）右上 32 高白底胶囊；收藏为右上星标。
- **DockTile**：88×88 r28 surface + 1 px outline，图标 40，下方 caption 标签；聚焦时放大 1.06、加焦点框、标签加粗。
- **GlyphBadge**：提示栏 34、行内 30、键盘角标 26。A/B/X/Y 圆形；L1/R1/L2/R2 r9 圆角方；
  Start/Select 胶囊；方向键用图形。提示栏用 glyph，内容里用 glyphSoft；按住类操作在徽标外圈画进度环。
- **Sheet**（底部面板，顶部 r28）、**Dialog**（最宽 560，r28，居中）、**QuickPanel**（宽 392，
  距右上 24，高度随内容）：头部、内容、底部提示栏之间用分割线。
- **Hud**：音量/亮度 280×56 胶囊，顶部居中，1.8 秒后淡出，不抢焦点，游戏中也显示。
  **Toast**：底部居中 2.4 秒；Sheet / Dialog 打开时放在其上方 16 px。✓ 图标只用于成功，提示类不带图标；
  文案不带句号。错误提示（底 #FBE9E7、字 #8E1D17）保留到下一次操作。
- **HoldConfirm**：屏幕中央卡片，88 环形进度 + 剩余秒数 + 一行后果；按住 0.6 秒后出现，松手即消失。
- **性能浮窗**：右上角，右边缘距屏幕右侧 32；游戏中顶边距 24，整个浮窗必须落在合成器的游戏放行区
  （1024×768 坐标 x 624–992、y 16–276，见 `gaming-wayland/handheld-shell.cpp`）；桌面上顶边 80，
  放在顶栏下方，不遮 Wi-Fi、电量和时间。r20，surface 92% 不透明 + 1 px outline，无模糊无阴影，
  宽 ≤ 360，不抢焦点；快捷面板打开时隐藏。数字等宽：第 1 行 label 22 粗体 accent（游戏中
  “60 FPS · 16.7 ms”，串流“串流 60 FPS · RTT 12 ms”，桌面“界面 12 次/秒”）；第 2 行 micro
  “CPU 1.30 GHz · 45% · GPU 400 MHz”；第 3 行 micro“52 °C · 内存 380 / 1024 MB”。一行放不下时
  只在“·”处折行。浮窗内容可在设置 › 性能里选“简洁 / 详细”：详细多 1 行 micro，游戏中
  “P95 18.2 ms”，串流“解码 3.1 ms · 丢帧 0.2%”；130% 字号下（含详细与折行）高仍 ≤ 252。
  没有数据的项整项隐藏，不显示“—”。游戏中音量 Hud 留在放行区内（音量显示时左界放宽到 x 396）；
  性能浮窗打开时，Hud 放在浮窗下方 16 px、与浮窗右对齐。

## 6. 动效

| 令牌 | 时长 | 曲线 | 用途 | 减少动态效果时 |
| --- | --- | --- | --- | --- |
| press | 80 ms | standard | 按下缩放 0.97、底色加深 | 只变底色 |
| focus | 120 ms | standard | 焦点框移动、卡片抬起 1.04 | 立即到位 |
| settle | 260 ms，一次 | standard | 焦点停稳后焦点框 1 → 1.03 → 1；连发时不播放 | 关闭 |
| page | 进 220 / 退 160 | emphasized | 新内容从右 48 px 滑入并淡入；返回向右 24 px 淡出 | 100 ms 交叉淡化 |
| sheet | 进 240 / 退 180 | emphasized / exit | 选项菜单升起、快捷面板滑入，遮罩同步 | 淡入淡出 |
| dialog | 进 200 / 退 140 | emphasized / exit | 0.96 → 1 并淡入 | 淡入淡出 |
| hud | 进 180 / 退 140 | standard | 浮层与轻提示，停留 1.8 / 2.4 秒 | 同左 |
| hold | 延迟 600 + 剩余时间 | linear | 按住确认的环形进度 | 同左 |
| theme | 200 ms | standard | 浅色 / 夜间整屏交叉淡化 | 直接切换 |

曲线：standard `cubic-bezier(0.25, 1, 0.5, 1)`，emphasized `(0.2, 0.9, 0.1, 1)`，exit `(0.4, 0, 1, 1)`。
约束：只动画 opacity、x/y、scale；同屏运动的大面积元素 ≤ 2 个且使用缓存图层；空闲时 0 个动画
（焦点框不呼吸）；输入不等动画，连续按键时动画立即改向；焦点移动只移动焦点框本身；
以 R46H 实机 60 Hz 帧间隔验收。

## 7. 按键体系

### 7.1 按键与分层

可用按键：方向键、左摇杆（L3）、A B X Y、右摇杆（R3）、L1 R1 L2 R2、Select、Start、音量 − / +、
电源（软件可读，事件来源待实机确认）。没有独立 Home 键，Select 兼任系统键。

输入分四层，上层处理过的按键不再下传：
1. 系统层：任何时候生效（电源、音量、Select 组合、L3+R3）。
2. 浮层：打开时独占输入（快捷面板、对话框、选项菜单、键盘、任务页）。
3. 页面层：桌面与 Jume 工具的通用语义。
4. 游戏：系统层以外的按键原样交给前台游戏；浮层打开时先给游戏发送一次中立状态。

### 7.2 系统层（全局，页面与工具不可占用）

| 按键 | 动作 | 桌面 | 游戏中 | 规则 |
| --- | --- | --- | --- | --- |
| Select 单按 | 快捷面板 | 打开 / 关闭 | 交给游戏 | 松开时判定；有浮层时 = 关闭浮层 |
| L3 + R3 | 快捷面板 | 打开 / 关闭 | 打开 / 关闭 | 游戏中唯一入口，见 7.5 |
| Select + Start 短按 | 回到主页 | 工具留在后台 | 游戏暂停并挂到后台 | 2 秒内松开；主页上无动作 |
| Select + Start 按住 2 秒 | 强制结束 | 前台工具 | 前台游戏 | 0.6 秒后显示 HoldConfirm；只作用于按下时的前台应用 |
| Select + Y | 任务切换 | 打开任务页 | 游戏暂停后打开 | 任务页内再按一次 = 返回 |
| 音量 + / − | 音量 ±5% | Hud | Hud | 按住 400 ms 后每 120 ms 一步 |
| Select + 音量 + / − | 亮度 ±5% | Hud | Hud | 最低 10% |
| 电源 短按 | 息屏 / 唤醒 | 立即息屏 | 暂停后息屏，唤醒后继续 | 息屏时第一个按键只负责唤醒 |
| 电源 按住 1.5 秒 | 电源菜单 | 息屏 / 重启 / 关机 | 同左，游戏先暂停 | 硬件长按关机保持不变 |
| Select + 其他键 | 不拦截 | 无动作 | 交给游戏 | 立即补发 Select 按下再转发；模拟器热键照常可用 |

### 7.3 页面层（每个键只有一种角色）

| 按键 | 建议动作名 | 角色 | 规则 |
| --- | --- | --- | --- |
| 方向键 / 左摇杆 | up / down / left / right | 移动焦点 | 可调控件上 ←→ 直接调整；到边界不循环（键盘行内除外），回弹 6 px |
| A | accept | 确认 | 开始、进入、切换、确认选择 |
| B | back | 返回 | 回上一级；顶层回主页；主页无动作；离开前保存，失败则留在原处并提示 |
| X | itemAction | 当前项的次要操作 | 作用于焦点项；每页最多一个，必须出现在提示栏 |
| Y | pageAction | 页面级操作 | 与焦点无关，如搜索、筛选、刷新；每页最多一个 |
| Start | options | 选项菜单 | 列出当前项全部操作（含 X/Y）；不可用项显示禁用并写原因 |
| L1 / R1 | prevSection / nextSection | 切换同级分区 | 标签、筛选、设置分类；首尾不循环；回到该分区上次位置 |
| L2 / R2 | pageUp / pageDown | 快速翻页 | 列表、网格每按一次整屏翻；按住不连发（7.5） |
| 右摇杆 | scroll（轴） | 滚动内容 | 只滚动视图，不移动焦点；推得越远越快 |
| L3 / R3 单按 | — | 不分配 | 只在 L3+R3 组合中使用 |

### 7.5 时序与判定

- 按下即生效，不等松开、不防抖。例外：Select、电源，以及当前场景带“按住”用法的键（如任务页的 X），
  短按在松开时触发。
- 方向连发：按住 380 ms 后每 90 ms 一步；列表按住超过 2 秒加速到 50 ms，网格不加速。
- 摇杆导航：死区为满量程 55%，只取主轴；回到 35% 以内算松开。
- 组合：按住 Select 时按另一键即为组合；两键 80 ms 内一起按下也算。
- 游戏中的 Select：松开时补发按下 + 松开；按住超过 600 ms 仍无组合，立即把按下交给游戏，此后不再判定组合。
- L3 + R3：单独按下照常透传；80 ms 内两者都按下时，给游戏补发松开并打开快捷面板。
- 长按：600 ms 后出现环形进度；电源菜单共 1.5 秒，强制结束共 2 秒；中途松开即取消。
- 连发：只有方向键和文字输入中的 B（退格）连发，其他键按住不重复。
- 键盘退格：按住 B 删到空就停，不会顺带关闭键盘；关闭需再单独按一次。
- 回到桌面：等所有键回到中立再接受输入。动画进行中输入不被阻塞。
- 边界反馈：焦点到头回弹 6 px；可选 20 ms 短振（pwm-vibrator），默认关闭。

### 7.6 提示栏

1. 右侧从右往左依次为 A、B、X、Y、Start；方向键提示放最左。
2. 最多 5 项，只显示当前可用操作；文案随焦点更新（“收藏 / 取消收藏”），2–4 字动词。
3. 左侧只放标题里没有的上下文（如“8 项”）；“Select 快捷面板”只在主页显示。不重复面包屑与选中状态，
   不显示 L1/R1（已画在标签两端）。普通的上下移动不提示；方向提示只用于有特殊含义的场合（如滑块“←→ 调整”）。
4. 浮层用自己的提示栏；游戏中不显示提示栏。
5. 提示栏由页面声明的动作生成，不在页面里手写。

## 9. 新工具接入清单

1. 使用共享顶栏与提示栏；提示栏由页面声明的动作生成。
2. 只声明 X、Y（各最多一个）和 Start 菜单项；不监听系统层按键。
3. B 永远返回；顶层 B 回主页；离开前保存，失败时留在原处。
4. 列表与网格用共享控件，自动获得翻页、滚动和焦点框。
5. 不可用的功能照常显示但禁用，并写明原因。
6. 按 7.7 选择直接执行、对话框或按住确认。
7. 文字 ≥ 18 px，焦点目标高 ≥ 56 px；130% 字号下关键信息不截断。
8. 动效只用透明度、位移和缩放，并支持减少动态效果。
9. 含密码、文件内容、终端输出的页面声明为不可远程截屏。
10. 声明后台策略（暂停或继续运行），任务页显示对应状态。
